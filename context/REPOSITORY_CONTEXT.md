# Repository Context

Existing mail automation structure:
- `mail_automation/`: Core mail automation package and implementation.
- `mail-automation-staging/`: Isolated environment for testing changes before production promotion.
- `docs/`: Product requirements, technical spec, architecture, roadmap, and traceability.
- `memory/`: Durable project state and safety policy defaults.
- `.claude/agents/`: IDE specialized agents (`mail-analyzer`, `mail-implementer`, `mail-security-reviewer`).
